# СПЕКТР

Учебная информационная система сервисного центра по ремонту и гарантийному обслуживанию электронной техники.

Приложение написано на PHP 8.2+, HTML, CSS и JavaScript. Данные хранятся в PostgreSQL 14+.

## Локальный запуск (Windows)

1. Установите PostgreSQL и PHP (можно использовать PHP из XAMPP).
2. Создайте пустую базу `spektr` и выполните `web/sql/schema.sql`, затем `web/sql/seed.sql`.
3. Включите в PHP расширения `pgsql` и `mbstring`.
4. Скопируйте `web/config.example.php` в `web/config.php` и укажите параметры подключения.
5. Запустите `start.bat` из корня репозитория.
6. Откройте в браузере http://127.0.0.1:8000.

Подробная настройка и тестовые учетные записи описаны в [web/README.md](web/README.md).

Для локальной работы не требуются Nginx, Apache, PHP-FPM, WSL или подключение к интернету после установки компонентов. PostgreSQL должен быть запущен на компьютере. Веб-сервер запускается самим PHP.

## Структура репозитория

- `web/public/` - страницы сайта, стили, скрипты и изображения.
- `web/src/` - серверная логика, авторизация и запросы к БД.
- `web/sql/` - схема и демонстрационные данные PostgreSQL.
- `web/config.example.php` - пример настроек подключения.
- `web/var/` - локальные данные приложения, включая сессии.
- `deploy/` - конфигурация Nginx и инструкция по развертыванию.
- `frontend/`, `backend/`, `database/`, `docs/` - зарезервированные каталоги; рабочий код находится в `web/`.
- `start.bat` - локальный запуск под Windows.

## Серверное развертывание

Для запуска с Nginx и PHP-FPM используйте [deploy/README.md](deploy/README.md). Встроенный веб-сервер PHP предназначен только для локальной разработки и демонстрации.

## Работа с Git

Создавайте отдельную ветку от `main` для каждой задачи и отправляйте изменения через Pull Request.
Не добавляйте в Git `web/config.php`, пароли, ключи и локальные данные.
