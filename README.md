# SPEKTR — Информационная система сервисного центра

Учебная информационная система сервисного центра по ремонту техники по дисциплине «Базы данных».

---

## Архитектура системы по ТЗ

Система спроектирована по трехзвенной клиент-серверной модели:
1. **База данных**: PostgreSQL 14+ (реляционная модель из 46 таблиц, ограничения целостности, индексы, транзакции).
2. **Сервер приложений (Бэкенд)**: PHP 8.2 REST API (расположен в каталоге [`backend/`](file:///I:/rgz_bd/backend/README.md)).
3. **Клиенты**:
   - Настольное приложение для сотрудников сервиса: **C# / WPF** (каталог `desktop/`).
   - Веб-приложение для клиентов и онлайн-заявок: **HTML / CSS / JS** (ветка `web_app`).

---

## Быстрый старт и запуск

### 1. Веб-интерфейс и REST API (через XAMPP)
* Веб-интерфейс доступен в браузере: **http://localhost:8080/**
* REST API доступен по адресу: **http://localhost:8080/api/**
* Проверка доступности: `GET http://localhost:8080/api/health`

### 2. Тестирование серверной части

* **Сквозные автоматические HTTP-тесты (23 теста)**:
  ```powershell
  powershell -ExecutionPolicy Bypass -File .\test_server_api.ps1
  ```
* **Модульные тесты сервисов и репозиториев (PHP)**:
  ```bash
  C:\xampp\php\php.exe backend\tests\run_tests.php
  C:\xampp\php\php.exe backend\tests\test_repository_pg.php
  ```
