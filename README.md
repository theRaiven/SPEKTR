# SPEKTR

Учебная информационная система сервисного центра по ремонту техники.

## Структура

- `frontend/` — веб-клиент (HTML, CSS, JavaScript).
- `desktop/` — настольный клиент (C# / WPF).
- `backend/` — PHP API, бизнес-логика и работа с PostgreSQL.
- `database/` — SQL-схема, миграции и тестовые данные.
- `docs/` — ТЗ, ER-диаграммы и документация API.

Папки пока пустые: каждый участник добавляет свою реализацию в соответствующий каталог.

## Работа с Git

Создавайте отдельную ветку от `main` для каждой задачи и отправляйте изменения через Pull Request.
Не коммитьте пароли, `.env`, ключи, сборки и локальные базы данных.
